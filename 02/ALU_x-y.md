# 證明：zx=0, nx=1, zy=0, ny=0, f=1, no=1 時，out = x − y

## 前提：二補數的「取反」

在 16 位元二補數中，把每個位元反轉（`!a`）再加 1 會得到 `-a`：

$$-a = \bar{a} + 1 \quad\Longrightarrow\quad \bar{a} = -a - 1$$

（因為 $a + \bar{a} = 1111\ldots1_2 = -1$。）

## 逐步代入 ALU 的運作規則

| 步驟 | 控制位元 | ALU 規則 | 結果 |
|-----|---------|---------|------|
| 1 | zx = 0 | 不把 x 清 0 | x |
| 2 | nx = 1 | x = !x | $\bar{x} = -x-1$ |
| 3 | zy = 0 | 不把 y 清 0 | y |
| 4 | ny = 0 | 不把 y 取反 | y |
| 5 | f = 1 | out = x + y | $\bar{x} + y = (-x-1) + y = y - x - 1$ |
| 6 | no = 1 | out = !out | $\overline{y-x-1} = -(y-x-1) - 1 = x - y$ |

所以

$$out = \overline{\,\bar{x} + y\,} = -\big((-x-1)+y\big) - 1 = x - y \qquad\blacksquare$$

## 實例驗算（用 4 位元示範，16 位元同理）

取 x = 5、y = 3，預期 out = 2。

| 步驟 | 二進位 | 十進位 |
|-----|--------|-------|
| x | 0101 | 5 |
| !x | 1010 | −6 |
| y | 0011 | 3 |
| !x + y | 1101 | −3 |
| !(!x + y) | **0010** | **2** = 5 − 3 ✔ |

再取 x = 3、y = 5（結果是負數）：

| 步驟 | 二進位 | 十進位 |
|-----|--------|-------|
| !x | 1100 | −4 |
| !x + y | 0001 | 1 |
| !(!x + y) | **1110** | **−2** = 3 − 5 ✔ |

## 對照官方測試

`ALU.cmp` 中 `zx=0 nx=1 zy=0 ny=0 f=1 no=1` 那一列，
x = 0000000000000000、y = 1111111111111111（−1）時 out = 0000000000000001（= 0 − (−1) = 1），
另一列 x = 0000000000010001（17）、y = 0000000000000011（3）時 out = 0000000000001110（14 = 17 − 3），
都和上面的推導一致；我的 `ALU.hdl` 已通過 `ALU.tst` 全部測試。
